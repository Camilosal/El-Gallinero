Por qué existe

Nació de una pregunta operativa, no de una idea de producto.

«¿Cuánto cuesta realmente una docena de huevos en Ambalá — y cuánto se gana vendiéndola?»

Identidad Cada gallina con raza, edad y etapa — no un número en un lote.
Trazabilidad Cada huevo rastreable hasta su venta.
Costo real Cada peso de alimento o vacuna, conectado al evento que lo generó.
Hoy 26 aves activas, trazabilidad financiera automática, cero cuaderno.

Pruébalo antes de instalar nada

La demo pública corre con meses de historial simulado — huevos, ventas, alimento, sanidad — para explorar el sistema completo sin tocar tus propios datos.

  • Cada ave con ficha propia: código, raza, edad, etapa
  • Vista de acceso rápido para el registro diario
  • Modo simple y modo avanzado, sin abrumar desde el día uno
  • Cada venta o tratamiento genera su transacción automáticamente
  • Funciona sin conexión — registra en el gallinero aunque no haya señal

La ficha técnica

Software libre publicado en GitHub bajo licencia abierta, pensado para que cualquier gallinero pequeño o mediano lo despliegue con su propia base de datos.

  • Next.js 16 + React 19 · Drizzle ORM sobre PostgreSQL · Tailwind CSS 4
  • 7 módulos, 25 tablas, reglas de negocio explícitas
  • docker compose up levanta app y base de datos en un paso
  • README con arquitectura, diccionario de datos y guía de contribución

El criterio de fondo

La misma disciplina que se aplica a cualquier sistema.

No es un caso aislado. Es evidencia de que el criterio se sostiene fuera de una presentación.

  • Modelar el proceso real antes que la pantalla
  • Conectar cada operación con su impacto financiero
  • Trazabilidad completa, sin reportes reconstruidos a mano
